description: デプロイ後の総合チェック（API疎通 + UI確認 + Discord接続）
---

複数のMCPを組み合わせて、デプロイ後の総合的なヘルスチェックを実行してください。

## チェック手順

### Phase 1: サーバー疎通（Fetch MCP）
1. 本番URLにアクセスしてHTTP 200を確認
2. `/api/bot/status` でBotの接続状態を確認
3. 主要APIエンドポイント5つにGETリクエスト

### Phase 2: UI確認（Playwright MCP）
1. トップページを開いてスクリーンショット取得
2. コンソールエラーの有無を確認
3. Bot接続ステータスが正しく表示されているか

### Phase 3: Discord確認（Discord MCP）
1. Botがオンラインか確認
2. スラッシュコマンドが登録されているか
3. テストチャンネルにping送信

### Phase 4: DB確認（SQLite MCP）
1. テーブルの存在確認
2. 最新のマイグレーションが適用されているか
3. 直近の取引レコードが正常に記録されているか

## 出力
- Phase別の結果サマリー
- 全てOK → 「デプロイ検証完了 ✓」
- 問題あり → 該当箇所と対処法
