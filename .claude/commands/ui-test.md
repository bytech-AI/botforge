Playwright MCPを使って、BotForgeダッシュボードの指定ページをテストしてください。

## 引数
$ARGUMENTS にテストするページパスを指定してください（例: `/points`, `/ai-scoring`）。省略時はトップページ。

## テスト手順
1. ブラウザで `http://localhost:5173{ページパス}` を開く
2. ページの読み込み完了を待つ（networkidle）
3. フルページスクリーンショットを取得
4. 以下をチェック:
   - コンソールエラーがないか
   - 要素のはみ出し・重なりがないか
   - テキストの切れ・表示崩れがないか
   - ボタン・フォーム要素が正しく表示されているか
5. 問題があれば該当箇所のスクリーンショットと改善案を提示

## 前提
- ローカルdevサーバーが起動していること（`npm run dev`）
