# スキル早見表（チートシート）

「/コマンド名」で実行。覚えなくても日本語で頼めばOK。

---

## 日常でよく使う（★）

| コマンド | やること | こう言ってもOK |
|---------|---------|---------------|
| `/dev` | 開発サーバー起動（5173+3001） | 「サーバー立てて」 |
| `/build-check` | ビルドしてエラー確認 | 「ビルド通るか見て」 |
| `/pick-issue` | GitHubのIssue取って作業開始 | 「次のIssueやろう」 |
| `/submit-pr` | コミット→プッシュ→PR作成 | 「PRにして」 |
| `/review-pr` | PRをレビュー | 「このPRレビューして」 |
