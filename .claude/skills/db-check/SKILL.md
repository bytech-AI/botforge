# データベース状態確認

1. 現在のDBスキーマ定義を確認してください。

`server/db/connection.js` の `initDatabase()` 関数を読み、全テーブルの構造を把握してください。

2. マイグレーション（ALTER TABLE文）を確認し、以下を報告してください：
   - 全テーブル一覧とカラム
   - マイグレーションの適用順序
   - 未適用のマイグレーションがないか
   - テーブル間のリレーション

3. `server/db/` 配下の各モジュールが使用しているテーブルの対応関係を報告してください。

4. 潜在的な問題（インデックス不足、型の不整合など）があれば指摘してください。
