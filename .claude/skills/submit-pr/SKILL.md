# Issue駆動開発：PR作成フロー

1. 現在のブランチ名と変更内容を確認してください。

```bash
git branch --show-current
git status
git diff --stat
```

2. 変更内容から適切なコミットメッセージ（日本語）を推測し、ユーザーに確認してください。
   - CLAUDE.mdの規約に従い、必ず日本語で書く
   - Co-Authored-By を含める

3. 確認が取れたら、コミットしてプッシュしてください。

4. ブランチ名からIssue番号を推測し（例: `issue-12-xxx` → `#12`）、PRを作成してください。
   - PRタイトルは日本語で簡潔に
   - bodyには「対応Issue」「変更内容」「テスト」「レビュー観点（ここが不安 / 別案あれば教えて）」を含める
   - CLAUDE.mdルール：レビュー側は最低1つ改善提案をする必要があるため、レビューしやすい観点を書く

5. PR作成後、URLをユーザーに表示してください。
