# BotForge RP ランクシステム仕様書

## 概要

2通貨制度: **RP**（ランク判定用）+ **CP**（消費用ポイント）

- **RP (Rank Point):** 活動で累積。ランクを決定する指標。直接消費はしない。
- **CP (Coin Point):** 消費・送金・ガチャ・報酬交換に使える通貨。CP獲得量にはランクによる倍率がかかる。

## ランク判定ロジック

### 累積RP方式

RPは0から無限に累積する。ランクは `rank_config` の `rp_threshold` と比較して判定。

```
resolveRank(config, currentRp):
  for each rank in config (order ascending):
    if currentRp >= rank.rp_threshold:
      matched = rank
  return matched
```

RP が増えればランクが上がり、減衰でRPが下がればランクも下がる。リセットや昇格ループはない。

## Xランク専用システム

Xランクは他のランクと異なり、独自のパワーゲージを持つ。

### 仕組み

1. 累積RPが60,000に到達 → Xランクに昇格
2. Xランク内で別カウンター **x_rp**（パワー）が開始
3. 以降のRP獲得は **x_rp** に加算される（累積RPは固定）
4. x_rp が降格閾値以下になると **S+** に降格

### Xランク設定

| 項目 | デフォルト | 説明 |
|------|-----------|------|
| max_rp | 3,000 | パワー上限 |
| entry_rp | 1,000 | X昇格時の初期パワー |
| demotion_threshold | 0 | この値以下でS+降格 |

### サブティア

Xランク内のパワー範囲でCP倍率が変わる。

| ティア | パワー範囲 | CP倍率 |
|--------|-----------|--------|
| X-I | 0 〜 999 | ×1.60 |
| X-II | 1,000 〜 1,999 | ×1.70 |
| X-III | 2,000 〜 3,000 | ×1.80 |

全てダッシュボードからカスタマイズ可能。

### 降格フロー

```
Xランク (x_rp: 500)
  ↓ 減衰で x_rp が 0 以下に
S+ランク (累積RP: 59,999, x_rp: NULL)
```

降格時:
- 累積RPは X閾値 - 1 に設定
- x_rp は NULL にクリア
- 再びRPを貯めてX閾値に到達すれば再昇格

## RP 獲得ルール

| アクション | RP量 | クールダウン | 日次上限 |
|-----------|------|------------|---------|
| message | +5 | 60秒 | なし |
| reaction_receive | +3 | なし | なし |

| thread_create | +10 | 300秒 | なし |
| contest_participate | +100 | なし | なし |

### 日次上限 (daily_cap)

`daily_cap > 0` の場合、その日の同アクションによるRP合計が上限を超えないよう制限。

```
getDailyRpTotal(guildId, userId, source):
  SELECT SUM(amount) FROM rp_transactions
  WHERE guild_id=? AND user_id=? AND source=? AND DATE(created_at) = today
```

## 減衰システム

### アクティブ減衰

サボった日だけRPが減る。活動した日は減衰なし。

| 設定 | デフォルト | 説明 |
|------|-----------|------|
| decay_rate | 2% | 1日あたりの減衰率 |
| decay_grace_days | 5日 | 非アクティブ日数がこの値を超えたら減衰開始 |
| decay_floor | 0 | RPの下限値 |

### 減衰計算

```
applyDecay(guildId):
  for each member (非免除 & 猶予期間超過):
    if Xランク:
      x_rp = floor(x_rp × (1 - decay_rate))
      if x_rp <= demotion_threshold → S+に降格
    else:
      current_rp = floor(current_rp × (1 - decay_rate))
      current_rp = max(current_rp, decay_floor)
      ランクを再判定
```

### 減衰免除

特定メンバーを減衰から除外できる。期限付きまたは無期限。

### 実行スケジュール

毎日 04:00 JST（Cronジョブ）に全ギルドで実行。冪等性保証あり。

## シーズンボーナス

### 概要

定期的にランク帯・順位に応じた **CP** を配布する。

| 設定 | デフォルト | 説明 |
|------|-----------|------|
| cycle_type | months | 周期タイプ |
| cycle_value | 1 | 1ヶ月ごと |
| start_date | 作成日 | 起算日 |

### ボーナス配分（CP）

**ランク帯ボーナス:**
| ランク | CP |
|--------|-----|
| X | 50,000 |
| S+ | 40,000 |
| S | 35,000 |
| S- | 30,000 |
| A+ | 25,000 |
| A | 20,000 |
| A- | 15,000 |
| B+ | 10,000 |
| B | 8,000 |
| B- | 6,000 |
| C+ | 4,000 |
| C | 2,000 |
| C- | 0 |

**順位ボーナス:**
| 順位 | CP |
|------|-----|
| 1位 | +50,000 |
| 2位 | +20,000 |
| 3位 | +10,000 |
| 4〜10位 | +5,000 |

### 実行フロー

1. Cronジョブ or 手動トリガー
2. RPリーダーボード取得
3. 各メンバーにランク帯 + 順位ボーナスを計算
4. `addPoints()` でCPとして付与
5. `season_history` に結果を記録
6. `last_season_end` を更新

**重要:** シーズンボーナスは**CPとして配布**（RPではない）。RPはリセットされない。

## CP倍率の適用

CPを獲得する全てのアクションにランク倍率が適用される:

```
実際のCP = 基本CP × getCpMultiplier(guildId, userId)
```

Xランクの場合、サブティアの倍率が使われる。
